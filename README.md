Calculadora básica que hace operaciones matemáticas, escrita en Python.
Como funciona
- El usuario elige una operación: sumar, restar, multiplicar o dividir.
- Introduce dos números.
- La calculadora muestra el resultado.
- Puedes hacer varias operaciones seguidas sin reiniciar el programa.
Como usarla
1. Ejecuta el archivo `calculadora.py`
2. Elige la operación (1 = sumar, 2 = restar, 3 = multiplicar, 4 = dividir)
3. Escribe los dos números
4. ¡Listo, te da el resultado!
Que aprendi:
- Funciones (def) 
- Condicionales (if / elif / else) 
- Bucles (while) 
- Entrada del usuario y conversión de texto a número
